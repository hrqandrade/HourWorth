# Changelog

All notable changes to HourWorth are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-22

### Added

- Five-area native iOS experience for Home, Projects, Track, Activity and Clients
- Client and project creation with fixed-price and hourly billing
- Timestamp-based timer and manual work entries
- Task progress and local activity history
- Manual payments with received and pending totals
- Effective hourly rate and project-value calculations
- Contextual project completion results
- Local persistence without an account or backend
- Swift Testing coverage and GitHub Actions validation
